# SegyViewer

**SegyViewer** - это настольное приложение для просмотра и анализа SEG-Y файлов (стандартный формат сейсмических данных). Приложение предоставляет интуитивный интерфейс для визуализации сейсмических трасс с возможностью настройки параметров отображения.

## Возможности

- **Загрузка SEG-Y файлов** - поддержка стандартного формата сейсмических данных
- **Интерактивная визуализация** - просмотр трасс с возможностью навигации
- **Настраиваемые параметры отображения**:
  - Количество трасс на странице
  - Шаг навигации по трассам
  - **Расширенные цветовые схемы** с улучшенной интерполяцией
  - Усиление (Gain) для улучшения видимости
- **Глобальная нормализация** - автоматическая нормализация амплитуд по всему набору данных
- **Информационные панели**:
  - Статус с координатами курсора
  - Детальная информация о заголовках трасс
- **Интерактивный зум** - выделение области левой кнопкой мыши, сброс правой кнопкой
- **Расширенное управление мышью** - panning правой кнопкой для навигации по зуму
- **Кэширование данных** - оптимизация производительности при работе с большими файлами

## Расширенные цветовые схемы

SegyViewer поддерживает профессиональные цветовые схемы, оптимизированные для сейсмических данных с использованием современных технологий цветовой интерполяции.

### Доступные схемы

#### **Базовые схемы**
- **`gray`** - классическая черно-белая схема для детального анализа амплитуд
- **`viridis`** - современная научная схема, дружественная к дальтоникам
- **`red_blue`** - классическая биполярная схема (синий-белый-красный)

#### **Профессиональные сейсмические схемы**
- **`petrel_classic`** - классическая схема Petrel с 11 ключевыми точками
- **`kingdom`** - профессиональная схема Kingdom с оптимизированными переходами

### Технические особенности

#### **Улучшенная интерполяция**
- **LAB цветовое пространство** - интерполяция в перцептивно равномерном пространстве
- **Множественные ключевые точки** - до 11 точек для максимальной плавности переходов
- **Гамма-коррекция** - настраиваемая гамма для оптимального восприятия

#### **Перцептивная коррекция**
- **Автоматическая коррекция** - учет особенностей человеческого зрения
- **Оптимизация для дальтоников** - схемы viridis и другие дружественные к цветовому зрению
- **Научная точность** - соответствие стандартам научной визуализации

### Детальное описание схем

#### **Petrel Classic (petrel_classic)**
- **11 ключевых точек** для максимальной плавности
- **Глубокий синий** → **белый центр** → **глубокий красный**
- **Оптимизирована** для анализа биполярных сейсмических данных
- **Профессиональный стандарт** в индустрии

#### **Kingdom (kingdom)**
- **11 ключевых точек** с улучшенными переходами
- **Темно-синий** → **голубой** → **белый** → **желто-оранжевый** → **темно-красный**
- **Высокий контраст** для детального анализа
- **Специально разработана** для сейсмической интерпретации

#### **Viridis (viridis)**
- **7 ключевых точек** для научной визуализации
- **Перцептивно равномерные** переходы
- **Дружественна к дальтоникам** и печати
- **Современный стандарт** научной визуализации

#### **Red-Blue (red_blue)**
- **3 ключевые точки** для простой биполярной визуализации
- **Симметричная схема** относительно белого центра
- **Классический выбор** для анализа амплитуд
- **Высокая производительность** благодаря минимальному количеству точек

### Расширенные возможности

#### **Настраиваемые параметры**
- **Контрастность** - множитель от 0.1 до 10.0
- **Яркость** - сдвиг от -0.5 до +0.5
- **Гамма** - коррекция от 0.5 до 3.0
- **Перцептивная коррекция** - автоматическая оптимизация цветов

#### **Пользовательские схемы**
- **Создание собственных схем** с произвольным количеством ключевых точек
- **Импорт/экспорт** цветовых схем
- **Динамическое добавление** новых схем во время работы

#### **Специализированные функции**
- **Автоматическая нормализация** амплитуд для оптимального отображения
- **RMS-адаптация** - подстройка под статистику данных
- **Биполярный/униполярный режимы** для разных типов сейсмических данных

## Интерактивный зум

SegyViewer предоставляет мощные инструменты для детального анализа сейсмических данных:

### Основные функции зума

- **Выделение области**: Левая кнопка мыши + перетаскивание для выбора области зума
- **Panning (перемещение по изображению)**: Правая кнопка мыши для перемещения по изображению в режиме зума
- **Быстрый сброс**: Двойной клик левой кнопкой для мгновенного сброса зума
- **Визуальная обратная связь**: Синий пунктирный прямоугольник показывает выделенную область
- **Постоянная подсказка**: Информация о зуме отображается в правой части статусной панели

### Управление мышью

#### **Левая кнопка мыши (ЛКМ)**
- **Зажатие + перетаскивание**: Выделение прямоугольной области для зума
- **Двойной клик**: Отмена зума (возврат к исходному масштабу)

#### **Правая кнопка мыши (ПКМ)**
- **Зажатие + перетаскивание**: Panning (перемещение по изображению) в режиме зума
- **Курсор-рука**: Автоматическое изменение курсора во время panning
- **Сохранение зума**: Уровень зума остается неизменным при перемещении

### Преимущества зума

- **Детальный анализ**: Увеличение интересующих участков для детального изучения
- **Сохранение контекста**: Автоматическое сохранение исходного состояния
- **Удобная навигация**: Panning позволяет легко перемещаться по увеличенному изображению
- **Производительность**: Оптимизированная перерисовка только при необходимости
- **Интуитивность**: Естественные жесты мыши для управления

### Примеры использования

1. **Анализ аномалий**: Выделите область с интересующими особенностями
2. **Сравнение трасс**: Увеличьте несколько трасс для детального сравнения
3. **Временной анализ**: Выделите горизонтальную полосу для анализа временного интервала
4. **Навигация по зуму**: Используйте правую кнопку мыши для перемещения по увеличенному изображению
5. **Быстрая навигация**: Используйте двойной клик левой кнопкой для мгновенного возврата к общему виду

## Графическая реализация

### Основная графическая библиотека: **Qt5 Widgets**

Приложение построено на основе **Qt5 Widgets** - мощного фреймворка для создания настольных приложений с графическим интерфейсом.

**Ключевые компоненты Qt5 Widgets:**
- **QWidget** - базовый класс для всех виджетов
- **QMainWindow** - главное окно приложения с меню, панелями инструментов и статусной строкой
- **QPainter** - система рисования для создания пользовательской графики
- **QLayout** - система компоновки для автоматического размещения элементов интерфейса
- **QGroupBox, QSpinBox, QComboBox** - стандартные элементы управления

### Пользовательская графика

Для отображения сейсмических данных используется **QPainter** - низкоуровневый API Qt для рисования:

- **Растровая визуализация** - каждый пиксель экрана соответствует определенной точке данных
- **Билинейная интерполяция** - плавное отображение данных с учетом разрешения экрана
- **Улучшенные цветовые карты** - преобразование амплитуд в цвета с множественными ключевыми точками
- **Адаптивное масштабирование** - автоматическое подстраивание под размер окна

## Особенности реализации

### Обработка данных
- **Потоковое чтение** - файлы читаются по частям для экономии памяти
- **Умное кэширование** - часто используемые данные сохраняются в памяти
- **Оптимизированная визуализация** - рендеринг только видимых областей

### Производительность цветовых схем
- **Предварительно вычисленные палитры** - LUT генерируется один раз для каждой схемы
- **Эффективная интерполяция** - O(1) доступ к цветам через индекс
- **Оптимизированная память** - использование std::vector для хранения цветовых палитр

### Качество визуализации
- **Множественные ключевые точки** - вместо простых линейных переходов
- **Гамма-коррекция** - для более естественного восприятия цветов
- **Профессиональные схемы** - основанные на научных исследованиях в области визуализации

### Система управления мышью
- **Интеграция с скроллбарами** - panning работает через управление скроллбарами MainWindow
- **Оптимизированная обработка событий** - минимальная задержка при panning
- **Визуальная обратная связь** - автоматическое изменение курсора для индикации режима
- **Умная активация** - panning доступен только при активном зуме (видимые скроллбары)

### Цветовые схемы

Система цветовых схем спроектирована с учетом современных требований к научной визуализации:

- **LAB цветовое пространство** - интерполяция в перцептивно равномерном пространстве для естественных переходов
- **Множественные ключевые точки** - до 11 точек вместо простых линейных переходов
- **Перцептивная коррекция** - автоматическая оптимизация цветов с учетом особенностей человеческого зрения
- **Профессиональные схемы** - petrel_classic и kingdom как стандарты индустрии
- **Настраиваемые параметры** - контрастность, яркость, гамма и перцептивная коррекция
- **Пользовательские схемы** - возможность создания и импорта собственных цветовых схем
- **Специализированные функции** - RMS-адаптация и поддержка биполярных/униполярных данных
